Tecnologías

  • HTML5 semántico y CSS3 sin frameworks, con diseño responsive.
  • JavaScript nativo para búsquedas, filtros, perfil e historial.
  • Aplicación web progresiva (PWA) con service worker para uso sin conexión.
  • Íconos Font Awesome 6 incluidos en el sitio, sin dependencias externas.

Navegadores compatibles

Últimas versiones de Chrome, Edge, Firefox y Safari, en computador, Android y iPhone.

Instalar como aplicación

  1. Chrome o Edge (computador): pulsa el ícono de instalar en la barra de direcciones.
  2. Android: abre el menú ⋮ y elige «Instalar aplicación».
  3. iPhone (Safari): toca Compartir y luego «Agregar a inicio».

Tus datos

Tu perfil, foto, hoja de vida (solo el nombre del archivo), postulaciones, vacantes guardadas, vacantes publicadas e historial de actividades se guardan únicamente en este navegador. No se envían a ningún servidor.
